# v0.1.0 · 单环境版本

首个版本将“关键字检索 → 预览 → 下载完整文件 → 补全跨文件上下文”封装为本地 MCP，通过 Playwright 操作可见浏览器，由 Codex / Claude Code 结合当前代码分析异常。

## 版本范围

- 每个 MCP 进程连接一个配置好的 Bxure 日志环境。
- 支持该环境中的多个 configurator、gateway、runner 实例。
- 7 个工具：`open_log_platform`、`list_instances`、`search_logs`、`preview_log`、`download_log`、`find_in_download`、`read_log_context`。
- 首次手动初始化和登录后复用浏览器状态，包括 IndexedDB 中的项目配置。
- HTTP Basic 下载认证、完整文件文本检索、前后编号文件补查和真实行号证据。
- 检索上限及上下文截断显式报告；确认平台上限后可自动拆分时间范围。

## 安装

需要 Node.js 22+。下载源码或发行包并解压，在目录中执行：

```powershell
npm ci
npx playwright install chromium
npm run build
Copy-Item config.example.json config.local.json
Copy-Item .env.example .env
```

编辑本地配置中的平台 URL 和 `.env` 中的下载认证，然后按 README 完成首次人工登录与 MCP 客户端接入。浏览器状态、下载日志及真实凭据不包含在发行包中。

## 验证

类型检查、8 项逻辑及协议测试、Chromium 集成测试和独立 STDIO 子进程测试通过。真实平台已验证：恢复初始化状态、列出 3 个实例、时间与关键字查询、预览、认证下载及前后相邻日志文件补查。

## 已知边界

每个进程仅使用一个环境；切换环境需修改本地配置并重启。页面预览可能不完整。平台实际结果上限尚未确认，默认返回 `completeness: "unconfirmed"`。相邻文件补查保持同实例、同日期，不推导跨日期轮转。时间连续性仅作为线索，仍需结合 traceId、线程和业务标识确认同一调用。
